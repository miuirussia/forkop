# URLTest

Группа, которая держит самый быстрый рабочий сервер секции. В неё попадают серверы этой секции, а какие именно, решает **Фильтр серверов**, устроенный так же, как [фильтр подписки](/connections/subscriptions#фильтр-серверов).

## Как выбирается сервер

По итогам первой полной проверки группа выбирает рабочий сервер с минимальной измеренной задержкой. Пока идут замеры, первое соединение может пройти через уже проверенный сервер.

При следующих проверках группа сравнивает текущий сервер с самым быстрым. Для каждого сервера она берёт медиану трёх последних успешных замеров. Пока замеров меньше трёх, используется последний. Группа переключается, если выигрыш превышает **Разницу задержки**. Неудачная проверка сбрасывает историю сервера. Если соединения через выбранный сервер начинают падать, группа может запустить проверку раньше интервала.

Если ядро поддерживает раздельные проверки TCP и UDP, Forkop включает проверку UDP для групп URLTest в секции, выбранной для каскадного подключения WireGuard, AmneziaWG, Phobos или WARP. Группа отправляет DNS-запрос `example.com` к `1.1.1.1:53` через каждый узел с поддержкой UDP и выбирает выход для UDP среди ответивших узлов. Для TCP используется URL проверки. В URLTest, добавленном через JSON, можно задать свой `udp_probe`.

| Параметр | По умолчанию | Что задаёт |
| --- | --- | --- |
| **URL проверки** | `https://www.gstatic.com/generate_204` | адрес для замера задержки |
| **Интервал проверки** | `3m` | как часто проверять серверы |
| **Таймаут проверки** | `5s` | сколько ждать результат проверки одного сервера, до `1m` |
| **Параллельные проверки** | `10` | сколько серверов одновременно проверять в одном прогоне TCP или UDP, от 1 до 64 |
| **Разница задержки** | `50` | на сколько миллисекунд выбранный сервер может быть медленнее самого быстрого |
| **Ожидаемый статус** | `*` | какие HTTP-коды считать успехом, например `204/200-299`. `*` значит любой ответ |
| **Таймаут простоя** | `30m` | через сколько остановить проверки, если через группу ничего не идёт |
| **Прерывать соединения** | выключено | закрывать открытые соединения при переходе на другой сервер. Включите, если после переключения старые соединения зависают на упавшем сервере |

Какие серверы попали в группу и какой выбран сейчас, показывает кнопка ⓘ на карточке группы на вкладке **Дашборд**.
Дашборд показывает последний замер каждого сервера. Описанный алгоритм, таймаут `5s` по умолчанию и настройка таймаута и параллелизма доступны с sing-box-forkop `1.14.4-r17`. На более раннем ядре оставьте поля **Таймаут проверки** и **Параллельные проверки** пустыми.

## URLTest или Fallback

URLTest смотрит только на скорость. Если серверы не равноценны, например свой сервер и запасная подписка, или нужен строгий порядок переключения, используйте [Fallback](/connections/fallback).
