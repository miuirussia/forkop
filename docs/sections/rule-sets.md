# Наборы правил

Свои списки доменов и подсетей для поля **Наборы правил**: по ссылке `https://…` или из файла на роутере.

Свои файлы удобно класть в `/etc/forkop/`, эта папка переживает обновление прошивки. Путь пишите полностью, например `/etc/forkop/my-list.txt`.

В поле **Наборы правил** также можно выбрать SRS из [sing-geosite](https://github.com/SagerNet/sing-geosite/tree/rule-set) и [sing-geoip](https://github.com/SagerNet/sing-geoip/tree/rule-set). Forkop сохраняет выбранный набор как ссылку на файл. Каталоги загружаются при открытии настроек правила и кэшируются в браузере на сутки каждый отдельно; при ошибке обновления используется сохранённый каталог. Сами SRS загружает и обновляет sing-box.

Для наборов **sing-geoip** включите в настройках набора **Учитывать IP-адреса и подсети**. В DNS-правилах предлагается только sing-geosite, поскольку sing-geoip содержит IP-подсети, а не домены.

## Форматы

Формат ядро определяет автоматически по содержимому.

| Формат | Что это |
| --- | --- |
| `.srs` | бинарный набор sing-box, так распространяются geosite и geoip |
| `.json` | исходный набор sing-box |
| текстовый список | по одному домену, адресу или подсети в строке |

Списки Clash в YAML не подходят.

## Текстовый список

```text
# Мои сайты
example.com
*.example.org
149.154.160.0/20
2001:67c:4e8::/48
```

| Строка | Что совпадает |
| --- | --- |
| `example.com`, `+.example.com` | домен и все поддомены |
| `*.example.org`, `.example.org` | только поддомены |
| `149.154.160.0/20`, `2001:67c:4e8::/48` | подсеть IPv4 или IPv6 |

Комментарии после `#` или `//` и пустые строки пропускаются. На любую другую непонятную строку ядро выдаёт ошибку.

## IP-адреса и подсети

Без настройки Forkop берёт из набора только домены. Чтобы учитывались и адреса с подсетями, включите у набора **Учитывать IP-адреса и подсети**.

::: warning Большие наборы подсетей
Каждая подсеть занимает память роутера. Двадцать тысяч подсетей требуют около 17 МБ, шестьдесят тысяч около 44 МБ, и роутер с 256 МБ такое может не выдержать. Включайте флажок, только если знаете, что делаете.
:::

## Обновление

Наборы по ссылке обновляются вместе со встроенными списками, см. [Обновление](/sections/lists#обновление).
