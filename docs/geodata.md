# Геоданные

Вкладка **Геоданные** управляет базами V2Ray/Xray `geosite.dat` и `geoip.dat`: ссылками, локальными файлами, расписанием и способом загрузки. Здесь же находятся настройки обновления обычных удалённых наборов SRS.

Для DAT требуется сборка **sing-box-forkop** с командой `sing-box geodata`. Старые команды `sing-box geosite` и `sing-box geoip` читают другой формат `.db`.

## Добавление базы

1. Добавьте источник, укажите название и тип **Geosite** или **GeoIP**.
2. Введите HTTP(S)-ссылку на DAT либо полный путь к файлу на роутере.
3. Настройте автообновление и интервал: от `5m` до `365d`, например `12h` или `1d`.
4. Сохраните и примените настройки, затем нажмите **Обновить**. Источник с включённым автообновлением также загрузится фоновым заданием при работающем Forkop.

Таблица показывает размер, число тегов, время последней успешной проверки и ошибки. Кнопка **Теги** открывает поиск по базе с выдачей по 200 тегов.

Настройка **Скачивать DAT через секцию** использует выбранное подключение работающего ядра. Первую базу можно скачать напрямую, когда ядро остановлено. Для первой загрузки через секцию сначала должно работать подключение, которое не зависит от ещё не загруженной базы.

## Использование в правилах

В поле **Наборы правил** нажмите **Выбрать тег DAT**, выберите источник и найдите тег. Один источник используется всеми секциями, без повторной загрузки базы.

Ссылка хранится в виде `dat:<идентификатор источника>:<тег>`. Например:

```text
dat:geodata_a1b2c3:youtube
dat:geodata_a1b2c3:google@cn
dat:geodata_a1b2c3:google@!cn
```

Фильтры `@атрибут` и `@!атрибут` можно дописать вручную. Кнопка **Скопировать ссылку на тег** на вкладке геоданных копирует ссылку с нужным идентификатором источника.

GeoIP автоматически учитывает адреса и подсети. В DNS-правилах доступны только теги geosite. Базы GeoIP с `inverse_match` отклоняются: инвертированный набор нельзя корректно экспортировать в подсети nftables.

Используемый источник сначала нужно убрать из правил, прежде чем удалять его.

## Память и хранение

Папка по умолчанию — `/tmp/forkop-geodata`. `/tmp` занимает оперативную память и очищается при перезагрузке; для больших баз лучше указать папку на внешнем накопителе. Для сохранения исходных локальных файлов во флеш-памяти подходит `/etc/forkop/`.

Ядро читает DAT потоком с буфером 32 КиБ и составляет индекс смещений. В SRS преобразуются только используемые теги, по одному за запуск. Поиск по каталогу и экспорт используют индекс; весь DAT в объекты памяти не загружается. Для GeoIP не создаётся промежуточный JSON или список строк CIDR.

Размер одного DAT ограничен 128 МиБ. При обновлении временно нужны исходная база, кандидат и новые SRS. После успешной подготовки старый управляемый DAT удаляется; предыдущие SRS сохраняются до следующего обновления. Файлы пользователя из локальных источников Forkop не удаляет.

Новая база сначала скачивается и проверяется, затем из неё собираются используемые теги. При ошибке загрузки, отсутствии нужного тега или ошибке конвертации продолжают использоваться предыдущие наборы. Одинаковое содержимое не компилируется повторно. Источники обновляются последовательно; при неудаче фоновое задание делает паузу перед повторной попыткой.
